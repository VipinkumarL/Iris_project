Viewer-Friendly API Demo

This page shows how another website can use IrisPass.

A normal user uses the register and login pages. An external website can instead call the biometric API directly. This demo shows that process step by step.

Step 1Check whether the API is online.
Step 2Capture an iris image and send it for register or login.
Step 3Read the response returned by the API.
Step 4Verify the saved token like another app would do.
